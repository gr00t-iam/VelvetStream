# VelvetStream logo assets

`velvetstream-logo.svg` is a native, editable vector variant with a transparent
background. It uses geometric paths without font dependencies. The monogram
combines a velvet-purple/indigo V with a continuous cyan-to-magenta soundwave.

`velvetstream-icon.png` is a 512 × 512 transparent rasterization of this SVG;
`velvetstream-vector-preview.png` shows it on charcoal.

`velvetstream-logo-concept.png` is a separate image-generation interpretation of
the same brief, not a rasterization of this SVG. The built-in image-generation
tool was used; its exact prompts are saved in `velvetstream-logo-prompt.txt` and
`velvetstream-logo-edit-prompt.txt`.
